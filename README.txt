SLIDE ESCAPE - iPhone PWA

1. Extract this ZIP file.
2. Create a new PUBLIC GitHub repository, e.g. slide-escape.
3. Upload the CONTENTS of this folder (index.html, sw.js, manifest.webmanifest, icon.png, icon-512.png) to the repository root.
4. GitHub repository > Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. Open https://YOUR-USERNAME.github.io/slide-escape/ on iPhone Safari.
6. Share > Add to Home Screen > Add.

Original puzzle-inspired implementation. Not affiliated with GiiKER.
